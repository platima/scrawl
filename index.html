Scrawl

4.5 KB gzipped · no deps

It draws wobbly SVG strokes behind your text, one per line box, so wrapping just works. Every stroke is seeded from the text itself, so it looks hand drawn but never changes between reloads. Ten shapes, no dependencies, and it respects reduced motion.

Built after digging through how Squarespace does its text highlights. Same idea, standalone, MIT. There is also a no JavaScript version if you only need static strokes.

The shape sheet

wrapping

    
Across line breaks

    
Strokes are measured per line box, so a run that wraps gets one stroke per line rather than a single stroke stretched across the gap. Resize the window and they redraw.

    

      The hard part was never the drawing, it was
      working out where the text actually sits once the browser has finished laying it out,
      because a span that wraps is not one rectangle, it is several, and
      the naive approach draws one enormous stroke through the middle of your paragraph
      which nobody wants.
    

  


  


  

    
install

    
Use it


    
Drop the script in, add a data-scrawl attribute, done. It self initialises on DOM ready.



<script src="scrawl.js"></script>

<p>Kept the good bits, threw out
  <span data-scrawl="scribble" data-scrawl-color="#d2372a">the busy parts</span>.
</p>


    
Or drive it from script:



Scrawl.annotate('#headline', {
  type: 'circle',
  color: '#1f8a5b',
  thickness: 3,
  animate: true
}).show();


    
Options

    

      
AttributeDefaultWhat it does

      
        
data-scrawlunderlineShape name. One of the ten above.

        
data-scrawl-colorinheritedAny CSS colour. Falls back to the element's own text colour.

        
data-scrawl-thickness0.085emStroke width in px. Scales with font size if you leave it alone.

        
data-scrawl-passes2How many times the pen goes over the whole figure. 1 is clean, 3 is scratchy.

        
data-scrawl-jitter10 is ruler straight. Above 1.5 gets messy quickly.

        
data-scrawl-opacity1Marker defaults to 0.32 so it does not bury the text.

        
data-scrawl-animatetrueDraw on reveal, triggered by IntersectionObserver.

        
data-scrawl-duration650Milliseconds per stroke.

        
data-scrawl-delay0Milliseconds before the first stroke. Use it to sequence a paragraph.

        
data-scrawl-directionrightWhich end the pen starts from.

        
data-scrawl-seedthe textChange it to get a different wobble for the same words.

        
data-scrawl-frontfalsetrue paints over the glyphs instead of behind them.

        
data-scrawl-repeatfalseRedraw every time it scrolls back into view.

      
    


    
Worth knowing

    

      The SVG is appended to the annotated element's parent at z-index: -1, and the parent
      gets position: relative if it was static. That keeps everything aligned through scrolling
      and transforms without any coordinate maths. If the parent has its own background you will want
      data-scrawl-front="true" instead. Redraws are debounced through a
      ResizeObserver on the parent plus document.fonts.ready, so a late web font
      does not leave strokes stranded under the old metrics.
