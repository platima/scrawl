no js

Scrawl CSS

One stylesheet, no script, and it still survives line wrapping because the stroke is a background, not an overlay.

Trade off: every instance of a shape looks the same, and there is no draw on animation. If you want per element wobble or the pen stroke reveal, use the JS build instead.

how

How it works

The stroke is an SVG background-image sized to a band under the baseline. Backgrounds already repaint per line box, so wrapped text is handled with no measuring, no resize listeners and no layout reads. Pick a shape class, then an ink class. 

<link rel="stylesheet" href="scrawl.css">

<span class="scrawl scrawl--scribble scrawl--red">
  like this
</span>

tuning

Inks and variables

Six ink classes ship with it: .scrawl--blue, .scrawl--red, .scrawl--yellow, .scrawl--green, .scrawl--lead and .scrawl--paper for dark backgrounds. Leave the ink class off for near black. Colour has to be baked into the SVG because a data URI cannot read a custom property, which is the one real limitation here. Adding your own is a copy, paste and swap two hex values.

PropertyDefaultWhat it does
--scrawl-height0.34emHow tall the stroke band is.
--scrawl-tile5.5emHow often the wobble repeats. Smaller means busier.
--scrawl-drop0emNudge the stroke further below the baseline.

Shorthand classes for the common tweaks: .scrawl--thin, .scrawl--thick, .scrawl--tight, .scrawl--loose, .scrawl--low.

wrapping

Long runs

The whole point of doing this with a background is that a run of text that spills across three or four lines still gets a stroke on every one of them, with no measuring, and it keeps working when the reader bumps their font size up.

box-decoration-break: clone is what makes each line fragment get its own copy rather than one background stretched across the lot.
